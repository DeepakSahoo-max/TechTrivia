# Tech Trivia — Frontend

React + Vite client for Tech Trivia. Tailwind CSS for styling, React Router for navigation.

## Getting started

```bash
npm install
npm run dev
```

The app runs on the port Vite prints in the terminal (usually http://localhost:5173).

Make sure the backend (see `../backend`) is running so login, sign-up, and quiz results work end to end.

## Available scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — build for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
